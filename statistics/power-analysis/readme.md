# Readme
- do one analysis per response (four responses per vignette)
- each response will have an expected difference from the flat prior, and intuitively this is what is modeled: ie how many datapoints are needed to have a solid KL difference from the prior?
- if the expected difference is big, few datapoints are needed, but if small difference, need many datapoints and thus many participants
- inull model: ratings do not systematically change with stakes / relationship / setting / etc.
- alternative model: ratings do systematically change with stakes / relationship / setting / etc.
